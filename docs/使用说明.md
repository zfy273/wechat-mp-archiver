# 公众号文章采集器 v3 · 使用说明

Windows 桌面程序（WinForms / .NET 6）。界面全部用系统自带控件（菜单栏、选项卡、GroupBox、
列表视图、日期选择器、状态栏），没有任何自绘和配色，和记事本、设备管理器那些老工具一个长相。

功能：把「上海市张江集团中学」公众号的文章与资源归档到本地，正文、排版、图片、语音都能离线打开。

---

## 一、两种用法

### 用法 A：登录一次，看目录，按日期一键爬（推荐）

1. 「公众号目录」页 → 点 **「登录…」**
2. 弹出的窗口里用微信扫码，登录**你自己的任意一个订阅号**（个人号即可，不用发文）
3. 回到主界面点 **「只拉取目录」** —— 列表里就会出现该号的全部历史文章（日期 / 标题 / 状态）
4. 想全部下载就直接点 **「拉取并下载」**；想只抓某段时间，就勾上 **日期范围** 的起止日期再点它

翻页是自动的：列表按时间倒序，程序从最新往回翻，翻到早于「起始日期」时就停下来，
所以"只抓 2024 年"不会白翻几百页。

### 用法 B：不登录，逐篇抓

1. 在微信里打开文章 → 右上角「…」→ **复制链接**
2. 切到「链接导入」页 → 点 **「粘贴剪贴板」**
3. 点 **「开始抓取」**

可以一次粘很多条，也可以直接粘一整段聊天记录，程序会自己把链接挑出来、去重。

> 说明：微信没有开放"免登录列出全部文章"的接口（老接口返回 `no session`，合集接口要会话，
> 搜狗的跳转链接会撞验证页）。所以**"看目录"必须登录**；不登录只能抓你手上已有的链接。

## 二、界面上都有什么

- **菜单栏**：文件（打开归档目录/退出）、采集（登录/拉目录/拉取并下载/下载勾选/停止）、帮助（说明/关于）
- **公众号目录**页：登录状态、公众号名称、日期范围、只拉目录/拉取并下载/停止、文章列表（可勾选）
- **链接导入**页：大文本框 + 粘贴/导入/清空/开始抓取
- **设置**页：归档目录、公众号名称、每篇间隔、每页条数、翻页间隔、保存图片/语音/Markdown
- **输出**面板：实时日志，成功绿字、失败红字、警告棕字
- **状态栏**：当前动作 + 进度条 + 总数统计

列表左边有勾选框，「下载勾选的文章（N）」按勾选走；也可以「全选 / 反选」。
双击一行：已归档的直接用浏览器打开离线页面，没归档的打开原文。

## 三、归档结构

```
D:\公众号归档\上海市张江集团中学\
├─ index.json                    ← 全部记录（含正文摘要，用于搜索）
└─ articles\
   └─ 2025-11-07_安全教育…_a1b2c3\
      ├─ index.html              ← 离线阅读页，图片全在本地
      ├─ article.md              ← Markdown，可导入笔记软件
      ├─ meta.json               ← 标题/作者/时间/原文链接/图片数/字数
      └─ assets\                 ← img_xxx.jpg、voice_xxx.mp3
```

列表里可以：搜索（标题/摘要/正文）、按状态筛选、导出 PDF、打包 ZIP、移除记录。

## 四、常见问题

**1. 拉目录时报"操作过于频繁"**
微信限流。等几分钟，再点一次「只拉取目录」，会从断点继续（已拉到的不会重拉）。

**2. 报"登录态已失效"**
后台 token 约 2~4 小时过期。重新点「登录…」扫一次即可。

**3. 单篇报"已失效"**
原文被作者删了或被平台屏蔽，不是程序问题。

**4. 单篇报"页面中没有正文"**
链接不完整，多半少了 `chksm` 参数。在微信里重新「复制链接」。

**5. 视频存不下来**
公众号视频是加密分片，无法离线保存，归档页会保留原链接。

## 五、命令行（可选）

```
张江公众号采集器.exe --fetch "https://mp.weixin.qq.com/s?__biz=...&mid=...&idx=1&sn=...&chksm=..."
```

接受一整段带杂字的文本，会自己挑出第一条链接。结果写到 `D:\公众号归档\手动导入\`。
